# Tesla 주가·뉴스 분석 및 다음 거래일 방향성 예측

Tesla 주가 데이터와 Tesla·Elon Musk 관련 뉴스 데이터를 결합하여  
주가 변동과 뉴스 감성·키워드의 관계를 분석하고,  
다음 거래일의 상승·하락 방향성을 예측한 데이터 분석 프로젝트입니다.

## 프로젝트 개요

- 분석 기간: 2023.01 ~ 2025.12
- Tesla 주가 데이터: 751 거래일
- 뉴스 원본: 2,232건
- 중복 제거 후 뉴스: 1,570건
- 뉴스가 존재한 거래일: 715 / 750일
- 뉴스 포함 거래일 비율: 95.33%

## 주요 분석

### 1. 뉴스 데이터 전처리
- 중복 뉴스 제거
- 소문자 변환 및 특수문자 처리
- 불용어 제거
- 표제어 추출
- 품사 기반 필터링
- 주식 거래일 기준 뉴스 날짜 정렬

### 2. 키워드 분석
급등일과 급락일의 뉴스에서 상대적으로 자주 등장한 키워드를 비교했습니다.

다중검정 보정 후 5% 유의수준을 충족한 키워드는 없었기 때문에,  
키워드 결과는 통계적으로 확정된 차이가 아닌 탐색적 결과로 해석했습니다.

### 3. FinBERT 감성 분석
FinBERT를 이용해 뉴스 헤드라인을 긍정·중립·부정으로 분류하고  
주가 급등일·평범한 날·급락일의 평균 감성 차이를 분석했습니다.

### 4. 기간 단위 분석
일별 데이터뿐 아니라 다음 단위로 데이터를 통합하여 분석했습니다.

- 일간: 750개
- 주간: 157개
- 월간: 36개
- 분기: 12개

주가 수익률, 뉴스 기사 수, 뉴스 감성의 흐름을 서로 다른 시간 단위에서 비교했습니다.

### 5. 머신러닝 예측
당일의 주가 및 뉴스 정보를 이용하여  
다음 거래일의 상승·하락 방향을 예측했습니다.

모델 및 변수 조합은 검증 데이터의 균형 정확도를 기준으로 선택했습니다.

## 최종 모델

**XGBoost + 주가 기술지표**

사용 변수:

- Daily_Return_pct
- Close_to_MA5
- Close_to_MA10
- Volatility_5d
- Volume_change_pct

## 모델 성능

- 검증 균형 정확도: 56.82%
- 테스트 정확도: 49.11%
- 테스트 균형 정확도: 48.14%
- 테스트 ROC-AUC: 53.36%
- 다수 클래스 기준 정확도: 54.46%

최종 모델의 테스트 정확도가 단순 기준 모델보다 낮아  
안정적인 일반화 예측력을 확보했다고 보기는 어려웠습니다.

## 주요 결론

- 뉴스는 전체 거래일의 95.33%에서 확인되어 거래일별 확보율은 높았습니다.
- 뉴스 감성과 키워드는 주가 급등·급락일 사이에서 일부 차이를 보였습니다.
- 일간뿐 아니라 주간·월간·분기 단위로 분석 범위를 확장했습니다.
- XGBoost와 주가 기술지표 조합이 검증 데이터에서 가장 좋은 성능을 보였습니다.
- 최종 테스트에서는 기준 모델보다 낮은 정확도를 보여 예측 성능의 한계를 확인했습니다.

본 프로젝트의 목적은 높은 투자 예측 정확도를 제시하는 것이 아니라,  
주가와 뉴스 데이터를 결합하여 관계를 분석하고  
탐색적 패턴과 실제 예측 성능 사이의 차이를 확인하는 데 있습니다.
